# Lab 8: HTML Forms, Sign-Up Forms and Choices

## 1. Experiment Title
HTML Forms, Sign-Up Forms and Choices

## 2. Aim
To create HTML forms using labels, text fields, email and password inputs, radio buttons and dropdown lists.

## 3. Software / Tools Required
- HTML5 and CSS3 (where applicable)
- Visual Studio Code or any text editor
- Git and GitHub (for Labs 1 and 2)
- Web browser (for HTML/CSS practicals)
- Command Prompt / Terminal (for Git practicals)

## 4. Theory
Forms collect information from users. The `form` element groups controls. The `label` element describes an input, while `input` creates fields such as text, email, password and radio controls. The `select` and `option` elements create dropdown lists. The `required` attribute enables basic browser validation.

## 5. Algorithm / Procedure
1. Create a form for user choices.
2. Add radio buttons with the same `name` to allow one selection.
3. Add a course dropdown using `select` and `option`.
4. Create a sign-up form with name, email and password fields.
5. Connect labels to controls using matching `for` and `id` values.
6. Use `required` where needed and test the form in a browser.

## 6. Program / Queries / Commands
Complete HTML source code is available in `index.html`.

## 7. Input
Enter sample name, email and password values; select a gender and course where applicable.

## 8. Output
