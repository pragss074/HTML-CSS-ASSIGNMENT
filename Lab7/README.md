# Lab 7: About Me Page Using Semantic HTML

## 1. Experiment Title
About Me Page Using Semantic HTML

## 2. Aim
To build a simple personal webpage using semantic HTML elements and navigation links.

## 3. Software / Tools Required
- HTML5 and CSS3 (where applicable)
- Visual Studio Code or any text editor
- Git and GitHub (for Labs 1 and 2)
- Web browser (for HTML/CSS practicals)
- Command Prompt / Terminal (for Git practicals)

## 4. Theory
Semantic HTML elements describe the meaning and role of content. `header` represents introductory content, `nav` contains navigation links, `main` holds the main page content, `section` groups related content, and `footer` contains closing or contact information. Semantic structure improves accessibility and maintainability.

## 5. Algorithm / Procedure
1. Create an HTML5 document.
2. Add a `header` with a page title and navigation links.
3. Use `main` and `section` to present personal information.
4. Add contact information inside a `footer`.
5. Use a `mailto:` link for the email address.
6. Open the page in a browser.
