# Lab 15: Responsive Web Pages with Media Queries

## 1. Experiment Title
Responsive Web Pages with Media Queries

## 2. Aim
To create responsive webpage layouts that adapt to different screen sizes using flexible CSS and media queries.

## 3. Software / Tools Required
- HTML5 and CSS3 (where applicable)
- Visual Studio Code or any text editor
- Git and GitHub (for Labs 1 and 2)
- Web browser (for HTML/CSS practicals)
- Command Prompt / Terminal (for Git practicals)

## 4. Theory
Responsive web design makes pages usable on different devices and screen sizes. Flexible layouts and images help content fit available space. A media query applies CSS rules only when specified conditions, such as a minimum viewport width, are met. A mobile-first approach starts with styles for smaller screens and enhances the layout for larger screens.

## 5. Algorithm / Procedure
1. Create an HTML page and link `style.css`.
2. Build cards in a single-column layout for small screens.
3. Make images flexible using `max-width: 100%` and `height: auto`.
4. Set readable base font sizes.
5. Add a media query for viewports at least 600px wide.
6. Change the card layout and heading size for wider screens.
7. Resize the browser window to test responsiveness.

## 6. Program / Queries / Commands
HTML code: `index.html`  
CSS code: `style.css`

## 7. Input
No external input is required. The layout responds to the browser viewport size. Add `images/sample-image.jpg` to display the sample image.

## 8. Output
The cards appear in a column on narrow screens and in a row on wider screens. The image scales to fit its container and the heading changes size. See `images/screenshot.png`.

## 9. Result
Successfully created a responsive webpage using flexible sizing and CSS media queries.
