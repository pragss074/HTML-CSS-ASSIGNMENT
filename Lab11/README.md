# Lab 11: CSS Units and Variables

## 1. Experiment Title
CSS Units and Variables

## 2. Aim
To understand fixed and relative CSS units and use CSS custom properties (variables).

## 3. Software / Tools Required
- HTML5 and CSS3 (where applicable)
- Visual Studio Code or any text editor
- Git and GitHub (for Labs 1 and 2)
- Web browser (for HTML/CSS practicals)
- Command Prompt / Terminal (for Git practicals)

## 4. Theory
CSS units specify dimensions such as width, height, spacing and font size. `px` is a fixed CSS unit, `%` is relative to a containing element, and `rem` is relative to the root font size. CSS custom properties are declared using names beginning with `--` and accessed using `var()`.

## 5. Algorithm / Procedure
1. Create an HTML page and link `style.css`.
2. Create boxes with pixel and percentage widths.
3. Apply a relative font size using `rem`.
4. Declare reusable custom properties inside `:root`.
5. Use `var()` to apply the defined colours and spacing.
6. Open the page in a browser.

## 6. Program / Queries / Commands
HTML code: `index.html`  
CSS code: `style.css`

## 7. Input
No external input is required; dimensions and variable values are defined in the stylesheet.

## 8. Output
The browser displays boxes with different units and text styled using CSS variables. See `images/screenshot.png`.

## 9. Result
Successfully demonstrated CSS units and reusable custom properties.
