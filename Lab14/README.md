# Lab 14: CSS Grid Layouts

## 1. Experiment Title
CSS Grid Layouts

## 2. Aim
To create two-dimensional webpage layouts using CSS Grid.

## 3. Software / Tools Required
- HTML5 and CSS3 (where applicable)
- Visual Studio Code or any text editor
- Git and GitHub (for Labs 1 and 2)
- Web browser (for HTML/CSS practicals)
- Command Prompt / Terminal (for Git practicals)

## 4. Theory
CSS Grid is a two-dimensional layout system that arranges items in rows and columns. `display: grid` creates a grid container. `grid-template-columns` defines columns, `gap` sets spacing, and `grid-template-areas` assigns named regions to layout elements.

## 5. Algorithm / Procedure
1. Create an HTML page and link `style.css`.
2. Create a numbered grid and define three equal columns.
3. Create a photo-gallery layout using responsive column sizing.
4. Create a dashboard with header, sidebar, main and footer regions.
5. Assign named areas using `grid-template-areas` and `grid-area`.
6. Open the page in a browser.

## 6. Program / Queries / Commands
HTML code: `index.html`  
CSS code: `style.css`

## 7. Input
Sample numbered cells, gallery placeholders and dashboard sections are included in the HTML file.

## 8. Output
The browser displays a numbered grid, photo-gallery grid and dashboard layout. See `images/screenshot.png`.
