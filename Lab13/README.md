# Lab 13: CSS Flexbox Layouts

## 1. Experiment Title
CSS Flexbox Layouts

## 2. Aim
To arrange webpage elements using CSS Flexbox for alignment, navigation and wrapping cards.

## 3. Software / Tools Required
- HTML5 and CSS3 (where applicable)
- Visual Studio Code or any text editor
- Git and GitHub (for Labs 1 and 2)
- Web browser (for HTML/CSS practicals)
- Command Prompt / Terminal (for Git practicals)

## 4. Theory
Flexbox is a one-dimensional CSS layout system for arranging items in a row or column. `display: flex` creates a flex container. `justify-content` aligns items along the main axis, `align-items` aligns them along the cross axis, `gap` adds spacing, and `flex-wrap` allows items to move onto additional lines.

## 5. Algorithm / Procedure
1. Create an HTML page and link `style.css`.
2. Create a row of cards and set its container to `display: flex`.
3. Use `justify-content`, `align-items` and `gap` to arrange the cards.
4. Create a navigation bar using Flexbox.
5. Create shop cards and enable wrapping using `flex-wrap: wrap`.
6. Open the page in a browser.

## 6. Program / Queries / Commands
HTML code: `index.html`  
CSS code: `style.css`

## 7. Input
Sample pricing cards, navigation links and stationery products are included in the HTML file.

## 8. Output
The browser displays centred cards, a Flexbox navigation bar and wrapping shop cards. See `images/screenshot.png`.

## 9. Result
Successfully used Flexbox to align, space and wrap webpage elements.
