# Lab 6: Types of HTML Lists

## 1. Experiment Title
Types of HTML Lists

## 2. Aim
To create ordered, unordered, nested and description lists in HTML.

## 3. Software / Tools Required
- HTML5 and CSS3 (where applicable)
- Visual Studio Code or any text editor
- Git and GitHub (for Labs 1 and 2)
- Web browser (for HTML/CSS practicals)
- Command Prompt / Terminal (for Git practicals)

## 4. Theory
HTML provides three common list types. `ol` creates a numbered list, `ul` creates a bulleted list, and `li` defines each list item. A description list uses `dl`, `dt` for a term and `dd` for its description. Lists can also be nested.

## 5. Algorithm / Procedure
1. Create an HTML document with separate sections.
2. Use an ordered list for the canteen menu.
3. Add a nested ordered list for menu choices.
4. Create a description list for frequently asked questions.
5. Create an unordered shopping list.
6. Open the page in a browser.
