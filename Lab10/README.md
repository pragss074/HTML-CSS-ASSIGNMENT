# Lab 10: CSS Fundamentals

## 1. Experiment Title
CSS Fundamentals

## 2. Aim
To apply inline, internal and external CSS to HTML elements using selectors and basic properties.

## 3. Software / Tools Required
- HTML5 and CSS3 (where applicable)
- Visual Studio Code or any text editor
- Git and GitHub (for Labs 1 and 2)
- Web browser (for HTML/CSS practicals)
- Command Prompt / Terminal (for Git practicals)

## 4. Theory
CSS (Cascading Style Sheets) controls the presentation of HTML pages. Inline CSS is written in an element's `style` attribute, internal CSS is written in a `style` element, and external CSS is stored in a separate file linked with `link`. Selectors target elements to apply properties such as colour, font size and text decoration.

## 5. Algorithm / Procedure
1. Create `index.html` and `style.css` in the same lab folder.
2. Link the external stylesheet in the document head.
3. Add an internal style block for selected elements.
4. Apply an inline style to a paragraph.
5. Use class and ID selectors in the external stylesheet.
6. Open the HTML file in a browser and compare the styles.

## 6. Program / Queries / Commands
HTML code: `index.html`  
External CSS: `style.css`

## 7. Input
No external input is required; the page contains sample headings and paragraphs.

## 8. Output
