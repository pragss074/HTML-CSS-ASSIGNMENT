# Lab 4: Divs, Attributes and Page Layout

## 1. Experiment Title
Divs, Attributes and Page Layout

## 2. Aim
To group webpage content using `div` elements and practise IDs and custom data attributes.

## 3. Software / Tools Required
- HTML5 and CSS3 (where applicable)
- Visual Studio Code or any text editor
- Git and GitHub (for Labs 1 and 2)
- Web browser (for HTML/CSS practicals)
- Command Prompt / Terminal (for Git practicals)

## 4. Theory
The `div` element is a generic block-level container used to group content. The `id` attribute uniquely identifies an element on a page. Custom data attributes, written with the `data-*` prefix, store extra information on HTML elements.

## 5. Algorithm / Procedure
1. Create an HTML document.
2. Add sections for an attendance report, profile information and page layout.
3. Use `div` elements to group related content.
4. Assign an `id` to an element and add a custom `data-*` attribute.
5. Open the page in a browser and inspect the displayed sections.

## 6. Program / Queries / Commands
Complete HTML source code is available in `index.html`.

## 7. Input
Sample attendance names, percentages and profile text are included in the HTML file.

## 8. Output
The browser displays the attendance report, profile text and header/main/footer layout. See `images/screenshot.png`.

## 9. Result
Successfully used `div`, `id` and custom data attributes to organise HTML content.
