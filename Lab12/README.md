# Lab 12: CSS Box Model, Cards and Scrolling

## 1. Experiment Title
CSS Box Model, Cards and Scrolling

## 2. Aim
To demonstrate the CSS box model, create a styled card and control overflow with scrolling.

## 3. Software / Tools Required
- HTML5 and CSS3 (where applicable)
- Visual Studio Code or any text editor
- Git and GitHub (for Labs 1 and 2)
- Web browser (for HTML/CSS practicals)
- Command Prompt / Terminal (for Git practicals)

## 4. Theory
The CSS box model consists of content, padding, border and margin. With `content-box`, width applies to the content area; with `border-box`, width includes content, padding and border. The `overflow` property controls content that exceeds an element's dimensions, and `overflow: auto` adds scrolling when needed.

## 5. Algorithm / Procedure
1. Create an HTML page and link `style.css`.
2. Create one element using `box-sizing: content-box`.
3. Create another element using `box-sizing: border-box`.
4. Style a card using padding, border and rounded corners.
5. Create a fixed-height box containing several lines of text.
6. Apply `overflow: auto` and view the page in a browser.

## 6. Program / Queries / Commands
HTML code: `index.html`  
CSS code: `style.css`

## 7. Input
No external input is required; sample boxes, card text and scrolling lines are included.

## 8. Output
