# Lab 5: Links and Images

## 1. Experiment Title
Links and Images

## 2. Aim
To create hyperlinks, internal navigation links and display images using HTML.

## 3. Software / Tools Required
- HTML5 and CSS3 (where applicable)
- Visual Studio Code or any text editor
- Git and GitHub (for Labs 1 and 2)
- Web browser (for HTML/CSS practicals)
- Command Prompt / Terminal (for Git practicals)

## 4. Theory
The anchor (`a`) element creates hyperlinks using the `href` attribute. An internal link can point to an element ID on the same page. The `img` element embeds an image; its `src` specifies the file and `alt` provides alternative text.

## 5. Algorithm / Procedure
1. Create an HTML page with navigation links.
2. Add sections such as Home and Portfolio with unique IDs.
3. Use anchor links to navigate between sections.
4. Add an image using the `img` element, with suitable `src` and `alt` attributes.
5. Open the page and test the links and image.

## 6. Program / Queries / Commands
Complete HTML source code is available in `index.html`.

## 7. Input
The page uses sample navigation links and an image path of `images/sample-image.jpg`.

## 8. Output
The browser displays the navigation and page sections. Add `sample-image.jpg` inside the `images` folder for the portfolio image to appear. See `images/screenshot.png`.

## 9. Result
Successfully created hyperlinks, internal page navigation and an image element.
