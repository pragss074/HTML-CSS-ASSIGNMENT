Lab 2: Pushing and Cloning a Repository

Aim

Send commits to a second repository on the computer and make a copy of it using clone.

Task 1: Create a Bare Repository

Create a remote repository and connect it as origin.

Task 2: Push Commits

Push commits from the local repository to origin.

Task 3: Clone Repository

Clone the remote repository into a new folder and check its commit history.

Git Commands

git init --bare ../html-remote

git remote add origin ../html-remote

git remote -v

git push origin main

cd ..

git clone html-remote html-copy

cd html-copy

git log --oneline

Conclusion

Successfully created a bare repository, pushed commits to the remote repository, and cloned it into a new folder.
