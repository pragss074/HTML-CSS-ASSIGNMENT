# Lab 3: Your First HTML Page

## 1. Experiment Title
Your First HTML Page

## 2. Aim
To create a basic HTML page using headings, paragraphs, line breaks and text-formatting elements.

## 3. Software / Tools Required
- HTML5 and CSS3 (where applicable)
- Visual Studio Code or any text editor
- Git and GitHub (for Labs 1 and 2)
- Web browser (for HTML/CSS practicals)
- Command Prompt / Terminal (for Git practicals)

## 4. Theory
HTML (HyperText Markup Language) is used to structure web pages. Elements such as `h1` to `h6` define headings, `p` defines paragraphs, `strong` indicates importance, and `em` adds emphasis. The `br` element inserts a line break.

## 5. Algorithm / Procedure
1. Create an `index.html` file.
2. Write the HTML5 document structure with `DOCTYPE`, `html`, `head` and `body`.
3. Add a greeting heading and different heading levels.
4. Add sample paragraphs and demonstrate `strong`, `em` and `br`.
5. Save the file and open it in a web browser.

## 6. Program / Queries / Commands
Complete HTML source code is available in `index.html`.

## 7. Input
No external input is required; the page contains sample text.

## 8. Output
The browser displays the greeting, heading levels, paragraphs and formatted text. See `images/screenshot.png`.

## 9. Result
Successfully created and viewed a basic HTML page using common text and heading elements.
