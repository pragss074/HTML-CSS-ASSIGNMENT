# Lab 9: HTML Tables with Headers and Footers

## 1. Experiment Title
HTML Tables with Headers and Footers

## 2. Aim
To display tabular data using table elements, captions, header rows, body rows and footer rows.

## 3. Software / Tools Required
- HTML5 and CSS3 (where applicable)
- Visual Studio Code or any text editor
- Git and GitHub (for Labs 1 and 2)
- Web browser (for HTML/CSS practicals)
- Command Prompt / Terminal (for Git practicals)

## 4. Theory
HTML tables organise data into rows and columns. `table` defines the table, `tr` defines a row, `th` defines a header cell and `td` defines a data cell. `caption` gives the table a title, while `thead`, `tbody` and `tfoot` group table sections. The `scope` attribute helps assistive technologies understand table headings.

## 5. Algorithm / Procedure
1. Create an HTML document containing a table.
2. Add a caption describing the table data.
3. Create column headings inside `thead`.
4. Add student marks inside `tbody`.
5. Add a class-average row inside `tfoot` where required.
6. Use `scope="col"` and `scope="row"` for accessible headings.
7. Open the page in a browser.
